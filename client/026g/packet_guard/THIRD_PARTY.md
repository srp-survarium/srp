The optional decoder and default C static library include `lzma-rust2` 0.22.0,
licensed under Apache-2.0. Source: <https://github.com/hasenbanck/lzma-rust2>.
The exact crates.io archive checksum is recorded in `Cargo.lock`.

Its code is unmodified. Default features are disabled, including `std`,
`optimization`, `encoder`, `lzip` and `xz`. This enables its safe `no_std`
decoder implementation. See `LICENSE-lzma-rust2` for the dependency license.

This project's code is GPL-3.0-or-later; see `LICENSE`. Redistributing the static
archive also requires preserving applicable dependency license notices.
